# ============================================================================================
# SHIP MESH ORIENTATION
#
# One line per mesh: <name> <pitch> <yaw> <roll> [scale] [spin|nospin]
# Edited and reloaded while the game runs (F10) — no recompile.
#
# The game's convention is Unity's: +Z is forward (the bow), +Y is up (the dorsal surface).
#
#   flying sideways?      try  0 90 0   or  0 -90 0
#   flying belly-first?   try  -90 0 0
#   flying backwards?     add  180 to the yaw
#
# ---- VERIFIED BY SILHOUETTE, NOT GUESSED FROM A BOX ----------------------------------------
#
# These lines were read off `tools/ship-silhouettes.mjs`, which rasterises each mesh's own geometry
# in the plane of its two longest axes — the top-down profile in which a bow is obvious — and marks
# the +axis direction in the corner of every cell. The sheet is `Art/AllModels/_silhouettes.png`.
#
# That mattered, because the previous generated pass had NEARLY THE WHOLE FLEET FLYING BACKWARDS.
# The bounding-box heuristic settles which axis a hull is long on and cannot settle which END is the
# bow — a box is symmetric. Measuring where the mass sits does not settle it either: a swordfish's
# sharp end is its bill and a shrimp's is its tail, so "the pointed end" is the bow on one hull and
# the stern on the next (`tools/measure-bow.mjs` reports both numbers and says so). The Aquarii
# creatures are almost all modelled facing -X, so the -90 yaw the generator wrote pointed every one
# of them tail-first along its course.
#
# THREE HULLS WERE ORIENTED ACROSS THEIR OWN BEAM, which no amount of 180s would have fixed: a manta
# ray carrier, a sea-turtle colony ship and a Terran scout aeroplane are all WIDER than they are
# long, so "the longest axis" found the wingspan and flew them sideways. Their length is the second
# axis, and their lines below say so.
#
# STATIONS DO NOT HAVE A BOW. Every one of them measures its shortest axis on Y, which means it is
# already a disc lying flat with its axis of symmetry up — so they take the identity rotation and
# are marked `spin`, which is what a radially symmetric structure with no facing should do.
#
# Re-running tools/make-orientation-manifest.mjs OVERWRITES THIS FILE and will undo all of it. Run
# the silhouette sheet again after it and re-read the verdicts.
# ============================================================================================
